OPERATOR REFERENCE

Using REcluse safely

Guidance for submitting samples, interpreting evidence, configuring enrichment, managing reports, and automating analysis through the local API.

On this page Quick startAdvanced optionsExternal uploadsReportsFastAPITroubleshooting

01 · ANALYSIS

Quick start

  1. Drop one suspicious file into the submission area or browse for it.
  2. Confirm the model and archive password. Common malware archives use infected.
  3. Open Advanced options only when you need enrichment or different limits.
  4. Select Begin isolated analysis, then open the job in Recent activity to follow its log and artifacts.
Accepted inputArchives, PE and .NET binaries, documents, PDFs, APKs, and scripts. The content classifier does not rely solely on the filename extension.

02 · CONTROLS

Advanced options

Tool-error limit
Stops an unproductive model/tool loop after repeated invalid or failed tool calls.
Reports directory
Root directory for the job's persistent report folder. Completed jobs are rediscovered after an application restart.
CAPE
Runs a locally hosted dynamic sandbox. No public-upload acknowledgement is needed.
Triage and VirusTotal
Search by SHA-256 first. The sample is uploaded only when the secondary upload option is selected and the hash has no usable result.
ANY.RUN and Joe Sandbox
Hosted dynamic services. Selecting upload is required before sample bytes are submitted.
abuse.ch
Performs hash-only correlation with MalwareBazaar, ThreatFox, and URLhaus. REcluse does not submit files to MalwareBazaar.
UnpacMe
Uploads only with explicit per-job permission and requests private processing when enabled in Settings and supported by the account.

03 · DISCLOSURE

External sample uploads

Hash searches should be the first pivot. A hash request does not transmit the sample contents, but it can still disclose investigative interest in that hash to the service.

For a public or community-facing upload, REcluse presents a warning and requires the exact word acknowledge. The API enforces the same rule server-side. Authorization applies only to that submitted job and is not saved as a default.

  • Check your organization's handling rules and the provider's current retention and sharing terms.
  • Assume a novel sample can identify a victim, campaign, or private investigation.
  • Use a private tenant or local CAPE instance when disclosure is unacceptable.

04 · EVIDENCE

Reports and artifacts

Reports retain the verdict, evidence references, indicators, analyst pivots, tool transcript, and optional enrichment artifacts. Provider detections are reputation evidence—not proof that behavior was observed during execution.

Jobs remain visible after restarting the WebGUI. Use Delete analysis and artifacts in the job drawer to remove a finished job and its managed report directory. Deletion cannot be undone.

05 · AUTOMATION

FastAPI integration

The WebGUI and REST API use the same job runner and persisted reports. Interactive OpenAPI documentation is available at /api/docs; the machine-readable schema is at /api/openapi.json.

MethodPathPurpose
GET/api/healthCheck service readiness.
POST/api/jobsSubmit one multipart sample and create a job.
GET/api/jobsList current and restored jobs.
GET/api/reportsSearch persisted reports by filename, hash, date, model, or verdict.
GET/api/jobs/{job_id}Poll status, log output, and artifact metadata.
GET/api/jobs/{job_id}/artifact-content/{path}Read a text or JSON artifact.
GET/api/jobs/{job_id}/artifacts/{path}Download an artifact.
DELETE/api/jobs/{job_id}Delete a finished job and its managed artifacts.

Common submission fields

FieldMeaning
sampleRequired multipart file. Maximum size is 2 GiB.
password, modelOptional overrides; omitted values use Settings.
max_turns, max_tool_errorsPositive analysis limits.
dynamic_providersComma-separated selection: cape,anyrun,joesandbox,triage.
dynamic_upload_providersComma-separated providers explicitly authorized to receive file bytes.
virustotal_enabled, abusech_enabled, unpacme_enabledEnable the corresponding optional enrichment for this job.
virustotal_upload_missing, unpacme_uploadSeparate opt-in to file submission; both default to false.
upload_acknowledgementMust equal acknowledge when public sample upload is requested.

A successful submission returns HTTP 202 with the job object. Poll until status becomes completed or failed; intermediate states are queued and running. Treat artifact paths returned by the job as opaque values and URL-encode them when constructing retrieval requests.

Submit a local, static-first job

curl -sS -X POST http://127.0.0.1:8743/api/jobs \
  -F 'sample=@/path/to/sample.zip' \
  -F 'password=infected' \
  -F 'virustotal_enabled=true' \
  -F 'virustotal_upload_missing=false'

This enables VirusTotal hash lookup but explicitly leaves file upload disabled.

Poll the job and retrieve an artifact

curl -sS http://127.0.0.1:8743/api/jobs/JOB_ID

curl -sS \
  http://127.0.0.1:8743/api/jobs/JOB_ID/artifact-content/ARTIFACT_PATH

Explicitly authorize a public upload

curl -sS -X POST http://127.0.0.1:8743/api/jobs \
  -F 'sample=@/path/to/sample.exe' \
  -F 'virustotal_enabled=true' \
  -F 'virustotal_upload_missing=true' \
  -F 'upload_acknowledgement=acknowledge'
API safetyDo not add the acknowledgement field mechanically to every request. Include it only after a human or an authorized upstream policy has approved that specific external upload. Bind the service to trusted interfaces and place authentication in front of it before allowing remote access.

06 · RECOVERY

Troubleshooting

Option is greyed out
Add the provider endpoint or API key in Settings, save, and reload the analysis page.
Job fails immediately
Open the job drawer and inspect the first error in the execution log. Verify the model identifier, endpoint, credentials, and Docker availability.
No hosted report found
A hash-first provider may return “not found” when upload was not authorized. This is expected and does not send sample bytes.
Previous report is missing
Confirm the configured Reports directory still contains its web-* job folder and that the application can read it.
